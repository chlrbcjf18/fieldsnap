# 현장스냅 (FieldSnap 대체 앱)

현장별 폴더 · 부재코드별 자동 번호(예: `GD-003`) · 촬영 직후 메모 · GPS/일시 스탬프 · ZIP + 사진대장(CSV) 내보내기.

## 사용
- **PWA**: GitHub Pages 주소 접속 → 접근코드 입력 → 브라우저 메뉴 "홈 화면에 추가"
- **APK**: Releases 탭에서 `현장스냅.apk` 다운로드 → 설치 (출처 불명 앱 허용 필요)

## 접근 제어
`www/access.js` 에 허용 코드의 SHA-256 해시만 들어 있습니다.
- 코드 추가: `tools/code.html` 을 브라우저로 열어 해시 생성 → 목록에 추가 → push
- 코드 삭제: 목록에서 해시 삭제 → push (앱 다음 실행 때 즉시 차단)
- 서버 로그인이 아니라 **자물쇠 수준**입니다. 코드를 아는 사람은 누구나 쓸 수 있으니 개인별로 코드를 따로 주고, 퇴사 시 삭제하세요.

## 데이터
사진은 폰 안(IndexedDB)에만 저장됩니다. 주기적으로 **백업·복원** 메뉴로 JSON 백업을 받아두세요.
